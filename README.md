# Sales & Demand Forecasting for Businesses

## Project Overview
This project forecasts future sales using historical business data from the Superstore dataset.

The objective is to help businesses make better decisions regarding inventory, staffing, and future planning.

## Dataset
- Sample Superstore Dataset
- Total Records: 9994

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Steps Performed
1. Data Cleaning
2. Missing Value Check
3. Duplicate Removal
4. Date Conversion
5. Feature Engineering
6. Sales Aggregation
7. Model Training
8. Forecast Generation
9. Visualization

## Model Used
Linear Regression

## Model Evaluation

MAE: 1797.51

RMSE: 2453.49

R² Score: 0.0108

## Visualizations
- Historical Sales Trend
- Actual vs Predicted Sales
- Future Sales Forecast

## Business Insights

- Historical sales data was analyzed to identify patterns.
- Future sales were forecasted using machine learning.
- Forecasting can help businesses plan inventory efficiently.
- Demand forecasting helps reduce stock shortages and overstock situations.
- Managers can use forecasts for budgeting and operational planning.
